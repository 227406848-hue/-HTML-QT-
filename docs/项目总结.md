# Dusk Patrol · Qt6 / OpenGL 飞行射击游戏 —— 项目总结

> 一句话：把 Claude 生成的 WebGL2 网页游戏 **Dusk Patrol** 用 **C++17 + Qt 6 + OpenGL 3.3 Core** 重写成桌面版。
> 属于**二次开发 / 重写**，不是原创玩法与美术；核心工程量在渲染管线、飞行模型、世界生成和音频。

## 2. 架构

Qt 6 的 RHI 每帧清屏重绘整个场景，往默认帧缓冲画会被整块覆盖，
所以走「离屏渲染 → 回读 → 交给 QML 显示」这条桥：

```
GameItem::updatePaintNode            （渲染线程，GL 上下文 current）
  ├─ Renderer::uploadWorld()          首帧上传地形/云纹理（内部先 ensureInit）
  ├─ Renderer::render(fs, w, h)       1/4 分辨率 FBO：地形 raymarch / 天空 / 云 / 机体 / 导弹 / 尾迹 / 粒子
  ├─ Renderer::takeFrame()            glReadPixels → QImage（alpha 必须为 1）
  └─ QSGSimpleTextureNode             Nearest 采样，放大成像素风
QML 层（Main.qml）                       叠 HUD / 仪表盘 / 输入
```

### 源码模块

```
src/World.*        噪声与地形/云生成（2048² 高度场，16 线程，约 0.1s）
src/FlightModel.*  飞行状态机（yaw/pitch/roll + omega 阻尼）
src/Mesh.*         飞机程序化网格（进气道 / 翼型放样 / 外倾双垂尾）
src/Trail.*        翼尖尾迹丝带（环形采样 + 屏幕空间带状展开）
src/Particles.*    爆炸粒子（火球 / 烟 / 水花 / 闪光）
src/SceneShader.h  地形 raymarch 着色器（GLSL ES 300 → 330 core）
src/Renderer.*     裸 GL：FBO、program、纹理上传、绘制、回读
src/AudioEngine.*  软件混音器 + 程序化爆炸音 + 音乐循环
src/GameItem.*     纹理桥 + 世界异步生成 + 每帧状态
src/GameWindow.*   QQuickView 子类：FPS、快照
qml/Main.qml       HUD / 输入 / 提示
assets/music/      背景音乐（CC0，见 assets/CREDITS.md）
docs/              截图、试听 WAV、原始 shader 参考
```

## 3. 做了什么

### 3.1 渲染
- 自定义 `QQuickItem` + `updatePaintNode`，自建 FBO 管线，裸 GL 3.3 Core（不用 Qt3D / Qt Quick 3D）
- 低分辨率（1/4）渲染 + Nearest 放大，得到像素化风格，同时省 GPU
- 天空 / 地形 / 云 / 机体 / 导弹 / 尾迹 / 粒子分层绘制，深度关系按渲染顺序处理
- `--snapshot` 无头渲染 N 帧后存 PNG，配合 FPS 统计做回归自检

### 3.2 程序化世界
- CPU 端多线程生成：2048×2048 高度图（float）+ RGBA 地表纹理、512×512 云图
- GLSL 里 raymarch 地形、云层、海面高光、太阳与机影投射
- 全程不加载任何外部贴图，只依赖数学

### 3.3 飞行与战斗
- yaw/pitch/roll 姿态 + 带阻尼的转弯角速度 `omega`
- 加力（燃油消耗 / 回充）、倒飞、360° 翻滚特技
- 三档视角（俯视 / 追尾 / 座舱）之间用位置与朝向插值平滑过渡
- 座舱 HUD 与仪表盘：速度带、高度带、俯仰梯、航向带、雷达、燃油条
- 挂架导弹（4 个挂点，打完 1 秒补挂）、爆炸粒子与尾迹

### 3.4 音频
- WinMM `waveOut` 自写混音器：4 块 × 512 帧轮转缓冲（约 46ms 延迟）
- 导弹爆炸实时合成：扫频低频冲击 + 低通噪声 + 起手爆裂
- 双声道等功率声像 + 距离衰减；爆炸时背景音乐 ducking
- 背景音乐为 CC0 芯片音乐循环（Juhani Junkala《5 Chiptunes (Action)》）
- `--audio-render out.wav` 离线渲染试听，不依赖声卡

## 4. 踩过的坑（面试可直接讲）

1. **RHI 清屏覆盖**：在 `beforeRendering` 往默认帧缓冲画 → 每帧被 Qt 清掉，场景全黑。必须走 FBO + 回读。
2. **`grabWindow()` 抓不到裸 GL 内容**（离屏重绘路径），快照改从自己的 FBO 读像素。
3. **alpha 必须为 1**：原版 shader 输出 `vec4(col, 0.0)`，WebGL canvas 设了 `alpha:false` 看不出问题，在 QML 里就是全透明。
4. **GL 的 `uv.y=0` 在屏幕底部**，天空渐变要翻。
5. **机影前后颠倒**：shader 里机影形状把机头摆在 +lz，而地面投影落在 -lz，`uPFwd` 要传反向。
6. **座舱视角必须不画机体**，否则眼点在机身里糊满屏幕。
7. **深水区海底高度是负数**（能到 -42），空气墙 floor 必须按 `max(seabed,0) + 9.5`，否则飞机会沉到水面以下。
8. **waveOut 缓冲不预热就永远不出声**：三块缓冲没人写过，`WHDR_DONE` 永不置位，混音线程永远等不到空闲块；启动时必须先 mix 一遍再 `waveOutWrite`。
9. **音频线程优先级不够会欠载**：实测只跑到 31k/44.1k 采样，声音断续；加 `timeBeginPeriod(1)` + `THREAD_PRIORITY_TIME_CRITICAL` 后正好 44k/s。
10. **首帧黑屏的真凶**：`updatePaintNode` 先 `uploadWorld` 后 `render`，而 `uploadWorld` 依赖 `m_inited`（GL 初始化在 `render` 里）。世界生成比首帧快时（加载音乐让启动慢 300ms 就撞上），首帧 upload 直接 return，但 `m_uploaded` 仍被置 true → 地形永远不上传 → 只剩 HUD、场景全黑。修法：`uploadWorld` 内部先 `ensureInit()` 并返回是否成功，调用方只在成功时置位。
11. **QML 里 `gameItem.muted` 拿到的是函数对象**（恒为真），要么用 `Q_PROPERTY`，要么加括号调用。
12. **GUI 程序在 Windows 看不到 stdout**，日志要自己落盘到 exe 旁边。

## 5. 怎么打开与运行

### 用 Qt Creator（推荐）
1. 打开 `D:\Qt\Tools\QtCreator\bin\qtcreator.exe`（已装 20.0.2）
2. 文件 → 打开文件或项目 → 选 `D:\workspace\dusk-patrol-qt\CMakeLists.txt`
3. Kit 选 **Qt 6.12.0 MinGW 64-bit**（首次会做一次 CMake 配置）
4. 点绿色三角运行；断点调试直接可用

### 用 VSCode（可以，但要配 CMake）
1. 装扩展：**CMake Tools**（微软）、**C/C++**（微软）
2. 打开文件夹 `D:\workspace\dusk-patrol-qt`
3. `Ctrl+Shift+P` → `CMake: Select a Kit` → 选 GCC 13.1（MinGW）或让它扫 `D:\Qt\Tools\mingw1310_64`
4. 在 settings 里给 CMake 加上 Qt 前缀：
   `"cmake.configureSettings": { "CMAKE_PREFIX_PATH": "D:/Qt/6.12.0/mingw_64" }`
5. 运行时需要 Qt 的 DLL 在 PATH：
   `"cmake.debugConfig": { "environment": [{ "name": "PATH", "value": "D:/Qt/6.12.0/mingw_64/bin;${env:PATH}" }] }`
6. 或者干脆在终端跑：`cmake -S . -B build -G Ninja` + `cmake --build build`

> 结论：**改代码 / 调 QML 用 Qt Creator 最省事**（Kit、QML 调试、设计器都现成）；VSCode 适合顺手改几行，但 Qt 环境变量得自己配。

### 命令行构建
```powershell
$env:PATH = "D:\Qt\6.12.0\mingw_64\bin;D:\Qt\Tools\mingw1310_64\bin;" + $env:PATH
cd D:\workspace\dusk-patrol-qt
cmake -S . -B build -G Ninja
cmake --build build
.\build\dusk-patrol-qt.exe
```

### 操作
- 鼠标位置 = 摇杆；按住**左键**加力；**右键**发射导弹；**T** 切视角；**空格**特技（单击倒飞 / 双击翻滚）；**M** 静音
- 自检环境变量：`DP_MUTE=1` 静音、`DP_VIEW=0/1/2` 指定视角、`DP_SKIM=1` 贴水面、`DP_AUDIO_DEBUG=1` 音频日志

## 6. 简历口径（照抄可用）

> **项目：Dusk Patrol · Qt6/OpenGL 飞行射击游戏**（2026.11）
> 以 C++17 + Qt6 重写 WebGL 原作 Dusk Patrol 的渲染核心：自定义 `QQuickItem` 与 OpenGL 3.3 管线把场景渲染到独立 FBO，再取回 `QImage` 交给 QML 显示，规避 RHI 每帧清屏覆盖；完成地形、云层、机体、导弹、尾迹与粒子的分层绘制和低分辨率像素化。
> 程序化世界：CPU 端值噪声 + Worley 噪声生成 2048² 地形高度图与地表纹理、512² 云图，GLSL 实现地形着色、海面高光、云影与机影投射，不加载外部贴图。
> 飞行与音频：yaw/pitch/roll + 阻尼转弯角速度，加力、燃油、倒飞与翻滚，三档视角插值；自写 WinMM 混音器（44.1kHz、4×512 帧轮转）合成爆炸与背景音乐，含声像、距离衰减与 ducking。
> 项目难点：绕开 RHI 每帧清屏改离屏 FBO 渲染；修复世界生成早于 GL 初始化导致的地形不上传黑屏；解决 waveOut 未预热与线程优先级不足造成的无声。

**可能被追问的点**：为什么用 FBO 而不是 Qt3D；1/4 分辨率怎么决定；raymarch 的性能瓶颈在哪；缓冲块数与延迟的权衡；爆炸音怎么合成；黑屏那个 bug 怎么定位的。
